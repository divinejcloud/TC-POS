Restaurant POS — Operations Guide
User Roles & Screens
RoleScreensMain Tasks

KitchenKitchen (KDS)Accept orders, set prep time, mark ready.

Order Lifecycle
  1. PENDING COUNTER – order created, waiting at the Counter. Table: Waiting for Counter Confirmation.
  2. CONFIRMED BY COUNTER – paid via Pay & Confirm, sent to the kitchen. Table: Occupied.
  3. ACCEPTED BY KITCHEN → PREPARING – kitchen accepts and starts cooking with an ETA. Table: Preparing.
  4. READY – cooked; waiters/counter get an alert. Table: Ready to Serve.
  5. SERVED – delivered to the guest. Table: Needs Cleaning, then tap it to make it Available.
  6. CANCELLED – rejected at the Counter (only possible before payment) or merged into another order.
Table Colors
  • Available free to use or reserve   Reserved held for a guest
  • Occupied / Waiting in use   Preparing kitchen cooking
  • Ready to Serve food is ready   Needs Cleaning clear and reset
First-Time Setup (Admin)
  1. Sign in with the default account admin / admin123 and immediately use Change Password (top-right user menu).
  2. Admin Setting → Settings: restaurant name, tax, service charge, Senior/PWD %, currency, timezone, receipt footer.
  3. Create Categories, then Menu items (price, station, picture), then Tables.
  4. Create Users for every waiter, counter and kitchen staff member.
  5. In the Apps Script editor run setupNightlyBackupTrigger once to enable the automatic midnight backup.
Dashboard Operations Workflow
  1. Create Order: tap + New Order, choose an Available table in the Basket (leave empty for Takeout), pick a category pill or use Search menu, and tap items to add them. Use × to remove a line. Tap Submit Order – the order goes to the Counter.
  2. Table cards: tap an Available table to reserve it. Tap a Reserved table to manage or clear the reservation. Tap a Needs Cleaning table to mark it clean. Tapping an in-use table frees it (asks for confirmation).
  3. Reservations: enter the guest / customer name, then Mark Reserved. The name shows on the table card. Tap a reserved table to edit the name, Clear Reservation, or Transfer the reservation to another Available table. A table that is in use cannot be reserved.
  4. Grid / List: the Grid / List buttons beside Merge Tables switch Active Orders between order cards and a compact table. The choice is remembered on this device.
  5. Active Orders list: shows order #, table, customer, waiter, item count, total, status and ETA countdown (red LATE when overdue). A cloud icon means the order is saved on this device and waiting to sync.
  6. Serve: the Serve button appears when the order is READY (or, if the Kitchen Display is disabled, as soon as it is paid).
  7. Transfer: Transfer moves an open order to another Available table; the old table is freed automatically.
  8. Merge Tables: Merge Tables moves all items from the Source table into the Target table order and frees the source table. Needs at least two active table orders.
  9. Ready alert: a pop-up and chime tell you when the kitchen finishes an order – tap Acknowledge & Serve, then serve the food.
Counter & Billing Workflow
  1. View mode: use the Grid / List buttons beside New Order to switch between card view and a compact table. Your choice is remembered on this device.
  2. Top cards: Pending Confirmation, In Kitchen / Serving (or Paid / To Serve), Unpaid Orders and Served Total.
  3. Pending orders (yellow): Pay & Confirm opens payment. Reject cancels the order (reason required) and frees the table.
  4. Payment window:
    • Enter an optional customer name.
    • Senior Citizen / PWD switch: ID # is required; the Senior/PWD % applies to the subtotal and replaces the manual discount.
    • Manual discount: up to 50% with a reason.
    • Delivery switch (Food Panda, GrabFood, Maxim, Others): recorded as Delivery, paid exactly (no change). Put the delivery order # in Reference #.
    • Philippine VAT: menu prices include 12% VAT by default (Settings → Menu prices already include VAT). Regular discounts come off the price and VAT is computed on what the customer pays. Senior/PWD: VAT is removed first (price ÷ 1.12), then 20% is deducted from the VAT-exclusive price, and the sale is VAT-exempt. Service charge is computed on the discounted amount. The receipt shows VATable Sales, VAT-Exempt Sales and VAT.
    • Enter Amount Received – Change is computed automatically. Choose Cash, Card, GCash or PayMaya and add a Reference # for non-cash.
  5. Confirm Payment: saves the payment, sends the ticket to the kitchen and opens the receipt preview. Press Print Receipt.
  6. Paid orders (blue): Reprint Receipt and Kitchen Ticket are available any time.
  7. Unpaid orders (red): orders that are READY/SERVED but unpaid show Process Payment.
  8. Print Kitchen Ticket: shows a preview; press Print Kitchen Ticket (80mm thermal). Use this to send orders to the kitchen when the KDS is disabled.
  9. Printer type: receipt and kitchen ticket previews have a printer selector – Thermal Printer (80mm) for receipt printers or Standard Printer (A4 / Letter) for regular office printers. The choice is remembered on this device.
Kitchen Display System (KDS) Workflow
  1. A chime and alert sound when the Counter confirms a new order. Each card shows ticket #, table, time, server and items with their station.
  2. Accept Order: tap Accept Order to acknowledge.
  3. Start Prep: enter the preparation time in minutes (default 15) and tap Start Prep. An ETA countdown starts; it turns red and shows LATE when overdue. The table becomes Preparing.
  4. Mark Ready: tap Mark Ready when cooked. Waiters and the Counter get an alert; the table becomes Ready to Serve.
  5. The red counter at the top shows how many orders are active.
  6. If the administrator disables the KDS, the Kitchen screen is hidden and paid orders go straight to serving – rely on printed kitchen tickets.
Admin Setting Operations
  • Stat cards: all-time Total Sales, Total Orders, Average Order Value and Tax Collected.
  • Settings: restaurant name, tax % (checkbox enables/disables), service charge % (checkbox), currency, timezone, receipt footer, Senior/PWD discount %, and Disable Kitchen Display System. Click Save Settings to apply. Reset Database only recreates missing sheets and default data – it does not delete existing records.
  • Menu: add or edit items (name, category, price, station, availability, picture). Pictures are compressed automatically. Unavailable items are hidden from ordering.
  • Tables: add, edit or delete tables. A table with an active order cannot be deleted.
  • Categories: add menu categories; they appear as pills when ordering.
  • Users: add staff with a role (Admin, Waiter, Counter, Kitchen). A blank password defaults to 123456 – ask staff to change it. Passwords must be at least 6 characters.
  • Activity Log: latest 300 actions (logins, orders, payments, settings). Use Refresh Logs to reload.
Sales Report
  • Pick Start/End dates (or use Today, Last 7 Days, This Month, All Time) and press Generate.
  • Shows net sales, gross subtotal, discounts, tax, service charge, items sold, average order, best day, peak hour, cancelled and open orders.
  • Breakdowns by payment method, delivery platform, category, station, hour, waiter and cashier, plus discounts (Senior/PWD vs manual).
  • Top Items, Daily Sales and a full Order Details list. Export CSV downloads the order details for Excel.
End of Day & Maintenance
  1. Choose the Business Date and press Generate Report. Review it, then Print (shows payments by method, cashier totals, all transactions, reference #s, Senior/PWD discounts, items sold and logins).
  2. Press Close POS for the Day. The report must be generated first. Closing makes a Google Drive backup, clears all orders, items and payments, and resets every table to Available. Make sure no offline changes are pending.
  3. Restore: Fetch Backups, select a file, press Restore. This replaces current Orders, OrderItems and Payments with the backup.
  4. Prune: Prune Old Backups moves backups older than 30 days to the Drive trash (also done automatically at night).
  5. Download ZIP: exports all sheets (except sessions) as CSV files in one ZIP.
  6. Automatic backup: once the trigger is installed, a backup is created every midnight (Asia/Manila by default).
Offline Mode
  • If the connection drops, orders, payments and status changes are saved on this device and a red banner appears. They sync automatically, in order, when the connection returns.
  • The top bar shows Synced, Retrying… or Offline with the number of queued changes.
  • You must be online to sign in. Do not log out with unsynced changes.
Troubleshooting
  • Cannot sign in: after 5 wrong attempts wait a few minutes. Admin can add a new password via Users.
  • "Invalid or expired session": sessions last 12 hours – sign in again.
  • Printing does nothing: allow pop-ups for this site.
  • Data looks old: the screen refreshes every few seconds; check the sync indicator.
  • Table stuck: tap the table card to free it (or Transfer / Merge the order).
  • Menu picture will not upload: choose a smaller image; large pictures are compressed but very large ones are rejected.
  • Wrong sale recorded: restore from the latest backup (Admin → End of Day & Maintenance).
