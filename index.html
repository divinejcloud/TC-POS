Tuna Choice POS — Operations Guide
User Roles & Screens
  • Dashboard: Manage table status, reservations, table transfers/merges, and new dine-in/takeout orders.
  • Counter: Settle orders (Single, Hybrid Split Cash + E-Wallet/Card, or Delivery), apply discounts (Manager/Admin PIN required for manual discounts), and process refunds (Manager/Admin PIN required).
  • Kitchen (KDS): Accept confirmed orders, set preparation ETA, and mark orders Ready to Serve.
  • Admin Setting: Configure restaurant settings, branches, menu items, users & Manager/Admin PINs, sales reports, and End-of-Day Z-Reading.
